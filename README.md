Cybersecurity Learning Diary

Welcome to my learning log. I am using this repository to track my day-to-day progress, document new concepts as I learn them, and stay accountable as I build my skills in cybersecurity.

## Why I'm doing this
- To build a consistent learning habit.
- To keep a record of what I study so I can look back and see how my skills have evolved.
- To practice summarising complex technical concepts in plain English.

## What I'm tracking
- General updates on concepts and methodologies I am studying.
- Problem-solving notes on things that tripped me up and how I figured them out.
- Weekly or daily milestones as I progress.
